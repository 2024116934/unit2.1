# Optional Guide: Run and Debug

The repository includes a Run and Debug configuration for each activity.

1. Open **Run and Debug** from the left-hand toolbar.
2. Select the activity you are working on.
3. Click beside a line number to add a breakpoint.
4. Press `F5`.
5. Use **Step Over** to follow the program one statement at a time.

For Activity 4, choose either the interactive application or the unit-test executable.

The program must compile before the debugger can start. Fix compiler and linker errors first.
